# Городская карта инфраструктуры

## Назначение

Приложение помогает отмечать на карте городские инженерные объекты, сохранять их геометрию и заметки. Данные хранятся в браузере пользователя.

## Основные сценарии

- Нарисовать площадь объекта кликами по карте (минимум 3 точки).
- Нарисовать линию или площадь, затем нажать «Готово». На компьютере также работает двойной клик; для линии нужно минимум 2 точки, для площади — 3.
- Указать номер, тип инфраструктуры и при необходимости описание.
- По запросу определить город и доступные части адреса по координатам объекта.
- Просматривать, редактировать и удалять объект; найти запись в списке заметок и перейти к ней на карте.
- Переключать спутниковую и схематичную подложку.

## Типы инфраструктуры

Газопровод, ЛЭП, водопровод, канализация, связь, земельный участок, теплосеть.

## Данные объекта

- Номер — обязательное текстовое значение.
- Тип инфраструктуры — обязательный выбор из списка выше.
- Геометрия — площадь (Polygon) или линия (LineString), координаты широты и долготы.
- Диаметр — необязательное числовое значение в миллиметрах.
- Глубина заложения — необязательное числовое значение в метрах.
- Описание — необязательный текст до 1000 символов.
- Дата создания и дата изменения.

Линейные объекты отображаются на карте линией; длина вычисляется по координатам и показывается в метрах или километрах согласно настройкам. Площади отображаются полигонами. При пересечении новой площади приложение предлагает открыть существующую запись или создать новую.

Определение адреса выполняется по отдельному действию пользователя через обратное геокодирование OpenStreetMap Nominatim. Отправляется только центральная координата геометрии; результат кэшируется в браузере. Точность и состав адреса зависят от данных OpenStreetMap. Требуется интернет-соединение.

## Хранение и запуск

При первом запуске пользователь заполняет ФИО, должность и организацию без пароля. До сохранения профиля карта и записи доступны только для просмотра; создание, изменение и удаление объектов заблокированы. Профиль, записи и настройки сохраняются в LocalStorage. Приложение запускается открытием `index.html`; для картографической подложки требуется интернет-соединение.
