# Городская карта

Простое веб-приложение для нанесения на карту городских инженерных объектов — площадями и линиями — и хранения заметок к ним.

## Возможности

- Рисование площадей и линейных объектов на карте.
- Каталог: газопровод, ЛЭП, водопровод, канализация, связь, земельный участок и теплосеть.
- Карточки объектов с номером, описанием и датой.
- Длина линии в метрах или километрах.
- Поиск по заметкам, номеру и типу объекта.
- Локальное хранение данных, профиль и выбор подложки.
- При первом запуске заполните профиль: до этого объекты доступны только для просмотра. Пароль не нужен.

## Запуск

Откройте `index.html` в браузере. Карта использует Leaflet, данные сохраняются в LocalStorage.
